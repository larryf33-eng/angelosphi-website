# Our Work images

Each sub-folder feeds one page on the site (`our-work-<category>.html`). The pages are generated by `build.py`,
which scans these folders — **to add a photo, drop it into the right folder and re-run `python3 build.py`.**
Name files like `interior-painting-13.jpg` (the name becomes the photo's alt text). Files are shown in natural number order (gaps in numbering are fine).
Resize new photos to about 1600px on the long edge (JPEG, quality ~82) before adding them, and strip location (GPS) data.
